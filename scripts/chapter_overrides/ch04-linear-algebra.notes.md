机器人里几乎所有「算一下位姿」都是同一件事：**一个几何对象（点、方向、一整块刚体）在某个坐标系里写成数字，再乘上一个矩阵，得到它在另一个描述下的数字**。本章把马上要用的概念讲完整；不收 SVD、Jordan 形、抽象公理。几何直觉跟 [3Blue1Brown Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra)，每个式子到 notebook 里画出来。

### 全书沿用的约定

后面运动学、TF、第 6 章刚体都按这一套，中途不要改。

1. **列向量。** 点或方向写成 \(\begin{bmatrix}x\\y\end{bmatrix}\)，变换写在左边：\(p' = A p\)。若把点写成行向量，公式会全部转置，两套混用必错。
2. **下标记坐标系。** \(p_b\)（也可写成 \({}^{b}p\)）是同一几何点在 **b 系** 下的坐标。
3. **齐次变换的下标（必须读懂，不要只记三个字母）。**

   \[
   p_a = T_{ab}\, p_b,\qquad T_{ac}=T_{ab}\,T_{bc}.
   \]

   \(T_{ab}\) 的含义是：**把 b 系里的坐标变成 a 系里的坐标**。它也等于「b 系相对 a 系的位姿」。箭头写法 \(T_{a\leftarrow b}\) 与 \(T_{ab}\) 同义，箭头指出数字从哪边变过来。

   **不要和另一种下标习惯混用。** 有的博客把 `T_ab` 说成「从 a 到 b 的变换」，公式会写成 \(p_b=T_{ab}p_a\)，和本书、*Modern Robotics* **正好相反**。本书以后只认：先写下标右边的系，乘完得到下标左边的系。

   **`@` 不是数学符号。** `p_a = T_a_b @ p_b` 只是 NumPy 代码（`T_a_b` 是合法变量名）。笔记、考题、和别人交流时用 \(p_a=T_{ab}p_b\)，不要把 `@` 写进公式。
4. **复合从右往左读。** 离向量最近的矩阵最先作用：先 \(T_{bc}\)（c→b），再 \(T_{ab}\)（b→a）。二维齐次用 3×3，三维用 4×4。
5. **角度。** 二维默认逆时针为正（右手系：大拇指指向纸面朝外）。notebook 里 `theta` 用弧度，`np.pi/2` 是 \(90^\circ\)。

### 1. 点、向量、坐标系

**点** 回答「在哪」：相对某个原点的位置。**向量** 回答「挪多少、朝哪」：有大小和方向，没有固定的起点。把向量的尾巴摆到原点时，它的头看起来像一个点——数字可以相同，含义不同。速度、力、两点之差是向量；路标在地图上的位置是点。

一组数字例如 \((1,2)\) **在没指定坐标系之前没有物理意义**。坐标系提供：原点在哪、两根（三根）轴朝哪、单位多长。同一根箭头，在世界系里可能是 \((1,0)\)，在转了 \(45^\circ\) 的车体系里就是另一对数字。

**运算：**

- 向量加法：首尾相接，位移合成。\(\vec{AB}+\vec{BC}=\vec{AC}\)。
- 数乘：\(2a\) 同向拉长一倍，\(-a\) 反向。
- 两点之差：\(\overrightarrow{PQ} = q - p\)，结果是向量。点加向量得到另一个点：\(p + v\)。
- 两点相加没有直接几何意义（除非先选定一个原点，把点暂时当成从原点出发的向量——机器人里要意识到自己在「借用」）。

**长度（欧氏范数）** \(\|a\|=\sqrt{a_x^2+a_y^2}\)（三维再加 \(a_z^2\)）。单位向量 \(\hat{a}=a/\|a\|\) 只保留方向。

**机器人里：** 激光点、关节在基座系下的位置是点；`cmd_vel` 的线速度、两帧之间的位移是向量。写代码先问：这组数字贴在哪个 frame 上？

### 2. 线性组合与基

平面上任意向量都可以写成 \(v = x\, e_1 + y\, e_2\)。\((x,y)\) 叫 **坐标**，\(\{e_1,e_2\}\) 叫 **基**。常用的世界系基是 \(e_1=(1,0),\ e_2=(0,1)\)，此时坐标就是分量本身。

基必须 **线性无关**（二维里就是不共线），否则有的方向拼不出来，或拼法不唯一。坐标唯一，当且仅当基是一组无关的、恰好铺满空间的向量（维数对得上）。

**几何：** 从原点沿 \(e_1\) 走 \(x\) 份，再沿 \(e_2\) 走 \(y\) 份，走到 \(v\)。换一组基，走的「份数」\((x,y)\) 就变，箭头本身不变。这是后面「基变换」的根。

### 3. 点积

**定义（分量）：** \(a\cdot b = a_x b_x + a_y b_y\)（三维再加 \(a_z b_z\)）。  
**定义（几何）：** \(a\cdot b = \|a\|\|b\|\cos\theta\)，\(\theta\) 是两向量夹角（取 \(0\) 到 \(180^\circ\) 那个）。

两式相等，所以：

- \(\cos\theta = (a\cdot b)/(\|a\|\|b\|)\)。算夹角用这个，注意先把分母非零、再把 \(\cos\) 夹到 \([-1,1]\) 再 `arccos`（数值误差）。
- **正交** \(\Leftrightarrow\) \(a\cdot b=0\)（有一个是零向量时也成立，但几何上「夹角」没意义）。
- **投影：** \(b\) 落到 \(a\) 所在直线上的向量是 \(\mathrm{proj}_a b = \dfrac{a\cdot b}{\|a\|^2}\, a\)。标量 \(\dfrac{a\cdot b}{\|a\|}\) 是有向投影长度。

点积交换：\(a\cdot b=b\cdot a\)。它 **不** 给出「左转还是右转」——那是叉积的事。\(\cos\) 对 \(\theta\) 和 \(-\theta\) 一样。

**小例子：** \(a=(3,4),\ b=(4,-3)\)。\(a\cdot b=12-12=0\)，\(\|a\|=\|b\|=5\)，夹角 \(90^\circ\)，投影是零向量。notebook 第 1 节应看到两箭头垂直。

**机器人里：** 两方向有多对齐（雷达法向与来车方向）、力在某轴上的分量、判断「是不是垂直」。单位方向 \(\hat{n}\) 上的分量就是 \(\hat{n}\cdot v\)。

### 4. 叉积

先分二维和三维，不要混。

**二维（本章主用）。** 把 \(a\times b\) 写成 **标量** \(a_x b_y - a_y b_x\)。几何上是以 \(a,b\) 为邻边的平行四边形的 **有向面积**：绝对值为面积，符号表示定向。本章约定：**正号 = 从 \(a\) 转到 \(b\) 是逆时针（左转）**，负号是右转。

例子：\((1,0)\times(0,1)=1\)（左转，面积 1）；\((1,0)\times(0,-1)=-1\)（右转）；\((2,0)\times(0,3)=6\)。平行则叉积为 0。

也可以把它想成三维叉积的 \(z\) 分量：把二维向量补 \(z=0\)，\(a\times b = (0,0,a_x b_y-a_y b_x)\)，垂直纸面。

**三维。** \(a\times b\) 是向量，方向用 **右手定则**（四指从 \(a\) 握向 \(b\)，大拇指为方向），大小 \(\|a\|\|b\|\sin\theta\)，等于平行四边形面积。\(a\times b\) 垂直于 \(a\) 和 \(b\) 所在平面。反交换：\(b\times a = -(a\times b)\)。平行则零向量。

公式（不必硬背，要会查会写）：

\[
a\times b=\begin{bmatrix} a_y b_z-a_z b_y\\ a_z b_x-a_x b_z\\ a_x b_y-a_y b_x \end{bmatrix}.
\]

**机器人里：** 力矩 \(\tau=r\times F\)；平面运动「向左为正」的角速度；两点与原点是否构成右手系；第 8 章雅可比里也会再见到叉积结构。本周先把二维符号画熟。

### 5. 矩阵是变换，不是一排数字

\(2\times2\) 矩阵 \(A=\begin{bmatrix} a_{11}&a_{12}\\ a_{21}&a_{22}\end{bmatrix}\) 规定一个从平面到平面的 **线性变换**：直线仍映成过原点的直线，原点不动，网格被均匀地拉斜、旋转或翻转。

**读矩阵的方法（3Blue1Brown 的核心）：** \(A\) 的 **第一列** 是基向量 \(e_1=(1,0)\) 被送到的位置；**第二列** 是 \(e_2=(0,1)\) 被送到的位置。任意 \(x=\begin{bmatrix}x_1\\x_2\end{bmatrix}\) 满足

\[
Ax = x_1\cdot(\text{第一列}) + x_2\cdot(\text{第二列}).
\]

所以你只要知道「单位正方形的两条边被送到哪」，整个平面的像就定了。notebook 里小房子的底边、竖边应对上这两列。

线性变换 **保原点**。纯平移会把原点搬走，因此 **不是** 线性变换，不能单独用 \(2\times2\) 矩阵表示——这是后面齐次坐标存在的理由。

**三维：** \(3\times3\) 的三列分别是 \(e_1,e_2,e_3\) 的像。

### 6. 矩阵乘法是变换的复合

若先做变换 \(B\)、再做变换 \(A\)（列向量约定），合起来是 \(A(Bx)=(AB)x\)。**离向量近的先作用**，所以书写顺序是 \(AB\)，阅读顺序从右到左。

一般 \(AB\neq BA\)。几何上就是「先转后移」和「先移后转」会把同一个点送到不同地方（题 5、notebook 第 3 节）。

结合律成立：\((AB)C=A(BC)\)，所以一长串变换可以任意加括号，但 **不能** 随便换左右顺序。

**单位阵** \(I\)：什么都不做，\(I x=x\)。二维是 \(\begin{bmatrix}1&0\\0&1\end{bmatrix}\)。

**机器人里：** 连杆 3 相对连杆 2、连杆 2 相对连杆 1、连杆 1 相对世界，写成一串乘；TF 树也是同一件事。顺序写反，末端会到镜子里。

### 7. 行列式

对 \(2\times2\)：\(\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc\)。  
几何：**单位正方形的有向面积，经过变换后变成多少**。也就是「两列所张平行四边形的有向面积」，恰好等于两列的二维叉积。

- \(|\det A|\) = 面积缩放倍数。\(\det A=2\)：面积翻倍；\(\det A=1/2\)：面积减半。
- \(\det A=0\)：面积被压成 0，两列共线，平面被压扁到一条线（或一个点），信息丢失。
- \(\det A<0\)：定向翻转，左手系变成右手系或反过来，图上像镜子。刚体在物理世界里不能靠连续运动把自己翻成镜像，所以 **旋转的行列式必须是 \(+1\)**。

三维行列式是平行六面体的有向体积，符号同样表示手性。本周会算 \(2\times2\)、会看符号即可。

**机器人里：** 检查 \(R\) 是不是旋转（\(\det\approx1\)）；数值 IK 附近若某雅可比行列式接近 0，就是奇异（第 8 章）。本章用房子图看 \(A,B,C,D\) 的 det（题 4）。

### 8. 逆：把变换撤回去

若存在矩阵 \(A^{-1}\) 使 \(A^{-1}A=AA^{-1}=I\)，则 \(A\) **可逆**。几何上：能把变过去的图无损变回来。

**存在条件：** \(\det A\neq 0\)。面积没被压扁，才能一一对应地回去。\(\det=0\) 时多对一，没有逆。

求 \(2\times2\) 逆：

\[
\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}.
\]

更高维用高斯消元或 `np.linalg.inv`。**但是刚体变换不要走通用求逆当第一选择：** 旋转的逆就是转置 \(R^{-1}=R^\top\)；齐次刚体的逆有闭式（见第 10 节）。通用 `inv` 有数值噪声，还可能在你写错、其实不可逆时扔一个很大的数出来。本章要求：手写 `invert_T`，再用 `inv` 对照，往返误差应 \(<10^{-12}\)。

若 \(C=AB\)，则 \(C^{-1}=B^{-1}A^{-1}\)（**袜子手套：后穿的先脱**）。和「从右往左做、从左往右撤」一致。

### 9. 转置、正交、旋转

**转置** \(A^\top\)：行列互换。点积恒等式：\(a\cdot b = a^\top b\)（把左边看成行）。对乘积：\((AB)^\top=B^\top A^\top\)。

**正交矩阵：** \(Q^\top Q=I\)（因而 \(Q^{-1}=Q^\top\)）。几何：各列是长度为 1、两两垂直的向量，即「把一组标准正交基送到另一组标准正交基」。长度和夹角都保持：\(\|Qx\|=\|x\|\)，\((Qx)\cdot(Qy)=x\cdot y\)。

正交还分两种：

- \(\det Q= +1\)：**旋转**（特殊正交，记 \(SO(2)\) 或 \(SO(3)\)）。右手系仍是右手系。
- \(\det Q= -1\)：**含反射**（广义正交 \(O(n)\) 里的另一块）。可以是镜子，或旋转再加镜子。列仍然单位正交，但手性反了。题 4 的 \(C,D\) 属于这类。

二维标准旋转（逆时针 \(\theta\)）：

\[
R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\ \sin\theta&\cos\theta\end{bmatrix}.
\]

第一列 \((\cos\theta,\sin\theta)\) 是 \(e_1\) 转过去的位置；第二列 \((-\sin\theta,\cos\theta)\) 是 \(e_2\) 转过去的位置（比第一列再超前 \(90^\circ\)）。\(\theta=90^\circ\) 时 \(R=\begin{bmatrix}0&-1\\1&0\end{bmatrix}\)，\((1,0)\to(0,1)\)，\((0,1)\to(-1,0)\)。

**检验一张矩阵是不是旋转：** 算 \(R^\top R\) 是否接近 \(I\)，再算 \(\det\) 是否接近 \(+1\)。只看「列看起来差不多垂直」不够。缩放 \(\mathrm{diag}(2,2)\) 保持角度但拉长长度，不是旋转。

### 10. 基变换：同一箭头，两套数字

设世界系基为 \(\{e_1,e_2\}\)，另一组基 \(\{e_1',e_2'\}\)（例如车体的前、左）。同一个几何向量 \(v\)：

\[
v = x\, e_1 + y\, e_2 = x'\, e_1' + y'\, e_2'.
\]

把新基在世界系下的坐标按列排成 \(R=\begin{bmatrix}e_1'&e_2'\end{bmatrix}\)，则

\[
\begin{bmatrix}x\\y\end{bmatrix} = R\begin{bmatrix}x'\\y'\end{bmatrix},
\quad\text{即}\quad
p_{\text{world}} = R_{\text{world}\leftarrow\text{body}}\, p_{\text{body}}.
\]

若 \(R\) 本身是旋转（新基也是右手单位正交），则 \(p_{\text{body}}=R^\top p_{\text{world}}\)。题 7：\(e_1'=\frac{1}{\sqrt{2}}(1,1),\ e_2'=\frac{1}{\sqrt{2}}(-1,1)\)，\(v_{\text{world}}=(1,0)\)，则 \(v'\approx(0.707,-0.707)\)。

**和「主动转物体」的关系：** 把物体上每个点乘 \(R(\theta)\)，是物体转了 \(\theta\)，坐标系没动。把坐标换成转了 \(\theta\) 的新基，是 **观察者转了**，物体没动。两种操作的矩阵经常互为逆。本周画图先固定 **点跟着矩阵走（主动）**；读 TF 时再切到「这个数字是在哪个 frame 里」。同一公式 \(p_a=R_{a\leftarrow b}p_b\) 两种故事都能讲，靠下标分清。

**机器人里：** 车上的速度在车体系是 \((v,0)\)，在世界系要乘上车的朝向 \(R\)；相机看到的点在相机系，进规划前要变到地图系。数字变了，点没有在空间里「瞬移」，只是换了一把尺子。

### 11. 齐次坐标：把平移也写进矩阵

线性变换保原点，**平移不保原点**，所以 \(p'=Rp+t\) 不能单用一个 \(2\times2\) 乘完。补一个永远是 \(1\) 的分量：

\[
\begin{bmatrix}x'\\y'\\1\end{bmatrix}
=
\begin{bmatrix} R & t \\ 0^\top & 1 \end{bmatrix}
\begin{bmatrix}x\\y\\1\end{bmatrix}
=
\begin{bmatrix}Rx+t\\1\end{bmatrix}.
\]

二维 \(T\) 是 3×3，三维是 4×4（\(R\) 为 3×3，\(t\) 为 3×1，最后一行 \((0,0,0,1)\)）。方向向量（只要旋转、不要平移，例如速度方向、平面法向）应补 \(0\) 而不是 \(1\)，否则会被错误地加上 \(t\)。本章点都补 \(1\)。

**逆（刚体，必须会手写）：**

\[
T=\begin{bmatrix}R&t\\0&1\end{bmatrix},
\quad
T^{-1}=\begin{bmatrix}R^\top&-R^\top t\\0&1\end{bmatrix}.
\]

推导：\(R p_b+t=p_a\) \(\Rightarrow\) \(p_b=R^\top(p_a-t)=R^\top p_a-R^\top t\)。不要去对 \(T\) 做符号意义上的「随便求逆」再抄进控制循环。

**复合：** \(T_{a\leftarrow c}=T_{a\leftarrow b}\,T_{b\leftarrow c}\)。乘开后新的旋转是 \(R_{ab}R_{bc}\)，新的平移是 \(R_{ab}t_{bc}+t_{ab}\)。这就是「先做右边那次刚体变换，再做左边那次」。

**何时必须用齐次、何时可以拆开写：** 只做一次「转转再加一个固定向量」，写 \(Rp+t\) 完全可以。要 **一串连杆、求逆、存成一个位姿、左右乘**，必须 3×3 / 4×4，否则括号和顺序会散架。题 8 就是认 4×4 的块。

函数 `T2(theta, t)` 的含义（与 notebook 一致）：**先绕原点转 \(\theta\)，再平移 \(t\)**，即 \(R\) 在左上、\(t\) 在右侧。先平移再旋转应写成 `R_homo @ T2(0, t)`，不能只改 `T2` 的两个参数以为顺序变了。

### 12. 特征值（本周只需几何，不展开计算流程）

方程 \(Av=\lambda v\)（\(v\neq0\)）：\(v\) 是 **特征向量**，\(\lambda\) 是 **特征值**。几何：沿这个方向，变换只缩放 \(\lambda\) 倍，**不转向**。\(\lambda<0\) 表示缩并且反向。

二维旋转（\(\theta\) 不是 \(0\) 或 \(180^\circ\)）通常 **没有实特征向量**——每个向量都被转走了，这和「旋转会动方向」一致。缩放 \(\mathrm{diag}(2,1/2)\) 的特征方向就是两根轴。

本周能用上面那句话解释图即可。对角化、特征分解做最小二乘/PCA/振动模态时再学（第 5、12 章）。不要为了「线代课完整」在这里推公式。

### 题目（先手算，再进 notebook 对答案）

做题时只允许纸笔或 `np.array` 验算，不要先翻参考。做完把对错记进文末表。每题都能在上面某一节找到对应解释。

**题 1（点积）** \(a=(3,4),\ b=(4,-3)\)。求 \(a\cdot b\)、\(\|a\|\)、\(\|b\|\)、夹角。\(b\) 在 \(a\) 上的投影向量是多少？这两个向量是否正交？

**题 2（叉积 / 定向）** 二维标量叉积：\((1,0)\times(0,1)\)、\((1,0)\times(0,-1)\)、\((2,0)\times(0,3)\)。哪个表示「从第一个到第二个是左转」？有向面积各是多少？

**题 3（旋转矩阵）** 写出绕原点逆时针 \(90^\circ\) 的 \(R\)。计算 \(R\begin{bmatrix}1\\0\end{bmatrix}\) 和 \(R\begin{bmatrix}0\\1\end{bmatrix}\)。验证 \(R^\top R=I\) 且 \(\det R=1\)。若把 \(\det\) 变成 \(-1\)（例如 \(\mathrm{diag}(1,-1)\)），图上的「小房子」会怎样？

**题 4（哪些是旋转）** 判断并说明理由：

\[
A=\begin{bmatrix}0&-1\\1&0\end{bmatrix},\ 
B=\begin{bmatrix}2&0\\0&2\end{bmatrix},\ 
C=\begin{bmatrix}0&1\\1&0\end{bmatrix},\

\]

**题 5（顺序，必错一次才算学过）** 点 \(p=(1,0)\)。变换甲：逆时针转 \(90^\circ\)，再平移 \((1,0)\)。变换乙：先平移 \((1,0)\)，再逆时针转 \(90^\circ\)。甲、乙之后 \(p\) 各到哪？用齐次矩阵写 \(T_\text{甲}\)、\(T_\text{乙}\)，确认 \(T_\text{甲}\neq T_\text{乙}\)。

**题 6（齐次复合与逆）** \(T_1\)：转 \(0\)、平移 \((2,0)\)。\(T_2\)：转 \(90^\circ\)、平移 \((0,0)\)。世界点从「物体系」出去：\(p_w = T_1 T_2 p_{\text{local}}\)（按我们的右乘约定，先 \(T_2\) 再 \(T_1\)）。取 \(p_{\text{local}}=(1,0,1)^\top\)（齐次），求 \(p_w\)。再算 \(T=(T_1 T_2)\) 的逆，验证 \(T^{-1}T-I\) 的最大绝对值应小于 \(10^{-12}\)。

**题 7（基变换）** 新基 \(e_1'=\frac{1}{\sqrt{2}}(1,1),\ e_2'=\frac{1}{\sqrt{2}}(-1,1)\)（相对世界系）。世界系下的向量 \(v=(1,0)\) 在新基下的坐标是多少？矩阵 \(R=[e_1'\ e_2']\) 满足 \(v = R\, v'\)，所以 \(v'=R^\top v\)（因为 \(R\) 是旋转）。

**题 8（对照三维，只认位置）** 一个 4×4 位姿里，左上 3×3、右侧 3×1、最后一行各是什么？若只把平移写成三维向量相加、旋转另乘，和乘 4×4 何时必须改用齐次（提示：还要复合、求逆、一串连杆）。
