# 附录 B 术语表

| 术语 | 含义 |
|------|------|
| FK / IK | 正 / 逆运动学 |
| SE(3) | 三维刚体位姿群 |
| EKF | 扩展卡尔曼滤波 |
| SLAM | 同时定位与建图 |
| RRT | 快速随机扩展树 |
| MPC | 模型预测控制 |
| \(T_{ab}\) | 把 b 系坐标变成 a 系坐标（本书 / Modern Robotics）。不是「从 a 到 b」。代码里才写成 `T_ab @ p_b` |
| TF | ROS 坐标系变换 |
| Nav2 | ROS 2 导航栈 |
| VLA | Vision-Language-Action 模型 |
| VLN | Vision-and-Language Navigation |
| Sim2Real | 仿真到真机迁移 |
