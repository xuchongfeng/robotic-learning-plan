# 章节模板

新开一章或改写旧章时，复制下列结构。正文只保留关键内容；细节进「推荐学习资料」。

```markdown
# 第 N 章 标题

| 字段 | 内容 |
|------|------|
| 状态 | 待学习 |
| 周次 | Week X–Y |
| 对应项目 | Px / 无 |
| 所属篇 | partK |

## 需要掌握

- 条目 1（可检查：能画、能算、能跑、能讲清）
- 条目 2

## 关键内容

用自己的话写本章最小闭环：几个概念如何接上、和哪一个实验/门禁对应。
不写长推导。易混点用一条对比说清。

## 推荐学习资料

### 必看（掌握本章）

- [名称](url) — 看到哪一节 / 跑哪条命令；用来过本章实验

### 进阶拓展

- [名称](url) — 更细推导、完整实现或研究方向；门禁加码或分流再用

## 实验清单

- [ ] 可验收的一条

## 笔记

自己的公式、踩坑、截图。不要把教材抄进这里。

## 复盘

- 卡住的地方：
- 下一章开始前必须补上的漏洞：
```
