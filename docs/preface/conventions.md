# 笔记与项目约定

## 章节状态

每章表格里的状态使用：`待学习` / `进行中` / `已完成`。

## 章节怎么写（必须遵守）

本书是 **提纲 + 笔记本**，不是第二本教材。每一章固定下列几块，缺一不可；**笔记在实验清单前面**，先把概念看清再动手：

| 块 | 写什么 | 不写什么 |
|----|--------|----------|
| 需要掌握 | 学完必须能复述或动手的知识点，条目化 | 完整证明、长公式推导 |
| 关键内容 | 本章最小闭环：概念关系、易混点、和项目的接口 | 把公开课讲义誊进来 |
| 推荐学习资料 | **必看**（过本章最低限度）和 **进阶拓展**（更细、更深、方向加码） | 无链接的空书名；和本章无关的清单 |
| 笔记 | 概念解释、自己的推导、踩坑、数字、截图 | 复制粘贴上游 README |
| 实验清单 | 可勾选、可验收 | 「了解一下」这类无法检查的句子 |
| 复盘 | 卡住的地方、下一章前要补的漏洞 | 把实验步骤再抄一遍 |

规则：

1. **正文宁短勿长。** 关键内容一般不超过一屏。推导、完整 API、论文细节一律放进「推荐学习资料」，用一句话标明看哪一节。
2. **每章必须有推荐资料，且分两层。** 必看用于过本章实验；进阶用于加码。加码整章的跳过规则见 [主干与加码](tracks.md)。
3. **资料要可执行。** 写清书名/课名、章节或 URL、建议看到哪。能跑的代码标出脚本路径。
4. **先资料，再笔记，再实验。** 先读必看，用「笔记」把概念讲清，再按「实验清单」动手；不要在正文里展开进阶。
5. **和公开课的关系。** 课表见 [公开课对照](courses.md)。本章只点名「跟哪一门的哪一段」，不代替那门课。
6. **路线标签。** 表格必须有「路线」列。非主干章文首加「可跳过」提示。
7. **公式。** 行内用 `\(...\)`，独立成行用 `\[...\]`。站点用 MathJax 渲染；不要用未经转义的 `$...$` 当主写法（容易和普通美元符号冲突）。

章节骨架见 [章节模板](chapter-template.md)。改章时保持标题层级不变，方便 MkDocs 导航。

## 项目目录

```
projects/
  p01_hello_robot/
  p02_kinematics/
  ...
```

每个项目至少包含：`README.md`（如何运行）、代码、大数据不要进 Git。

篇结束时对照 [门禁](../projects/gates.md)：没有数字指标、没有失败记录，视为未通过。

## 引用外部代码

允许阅读与对照 PythonRobotics、d2l-ros2、every-embodied，**提交到本仓库的代码必须是你改过或重写过的最小可运行版本**，并注明上游链接。
